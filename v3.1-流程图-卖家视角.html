🎯 小红书选品 · 卖家工作流

从"不知道卖啥"到"开始卖货"的 5 步流程 · 6 周 / 95-120 小时

1
📝 我想卖啥？
——输入关键词 + 选品类 + 选方向，30 秒判断能不能做
你只做 3 件事：
① 输入一个产品关键词（比如"防晒霜""瑜伽服""手机壳"）
② 选 1 个品类（9 大品类：实物/半标品/虚拟/知识付费/大牌平替/新奇特/周期/男性蓝海/高客单蓝海）
③ 选 1-2 个方向（7 大方向：功能性半标品/红海蓝海/美妆/自带流量/大牌平替/新奇特/知识付费）
如果你输入"减肥药""壮阳药""医美"——工具会**立刻弹出红色警告**（黑五类不推广 + 不提供货源 + 不引导引流方式）。这步不用你判断，工具自动拦截。
不确定选哪个方向？工具会根据"你输入的关键词 + 行业方法论"自动推荐 1-2 个适合的方向。
2
🔍 这个品能爆吗？
——AI 看市场数据 + 商家图，判断"卖这个能不能赚钱"
工具自动跑 3 件事，**你不用操作**：
2.1 · 看数字
抓 7 个数据源
小红书主数据 + 千瓜品类榜 + 灰豚商品榜 + 蝉妈妈视频榜 + 巨量算数 + 抖音精选联盟 + 小红书 APP 搜索
2.2 · AI 读数字
文本分析
痛点 vs 痒点 / 蓝海三要素（稳定流量+产品很差+稳定变现）/ 跟品爆品 / 中高端定位（拒绝低价走量）
2.3 · AI 看图
视觉分析
候选品封面图 + 商家商品主图（识别 P 图/盗图/低质图）
2.4 · 出报告
4 板块输出
市场概况 / 爆款潜力 / 选品建议 / 货源推荐
❓ 这个品能"中高端 + 痛点 + 蓝海"3 要素都满足吗？
❌ 不满足 → 直接放弃，看下一个品
✅ 满足 → 进入第 3 步
3
🛒 在哪能拿到货？
——AI 帮你找 1688/拼多多/淘宝 同款 + 算利润 + 评商家
选中候选品后，工具自动反查 3 个货源平台：
3.1 · 同款匹配
找货源
工具在 1688/拼多多/淘宝 自动找同款/相似款 + 售价 + 起订量
3.2 · 商家打分
双轨评分
小红书商家 + 货源商家 **分别 0-100 打分**（销量/评价/经营时长/AI 风险）
3.3 · 算利润
利润空间
售价-成本-物流-平台费 = 净利润 + 投资回报率
3.4 · 验真伪
假数据检测
24h 突然爆 10x → 标"疑似刷量" + 传统电商平台交叉验证
**双轨评分**是这个工具的关键差异化：别家只评"小红书商家"，我们同时评"货源商家"——避免你被货源端坑。
4
🧪 怎么知道这个品能卖？
——【有颜】测 5 条，【有用】多测几天，每天 3 个新品入库
工具自动判断你的品是 **【有颜】**（饰品/服装/手机壳/鞋子/宝宝用品）还是 **【有用】**（功效品/工具/服务），然后用**不同的测品策略**：
👗 【有颜】测品
重点：选款式
小红书搜产品名 → 按"最热"排序 → 找 2-3 张同风格图 → 1:1 模仿（文字+颜色+布局）→ **5 条左右**测试
🛠️ 【有用·已爆】测品
改字派
直接在原爆款标题改几个字 + 标签 → 多测几天
🛠️ 【有用·未爆】测品
卖点重组
4 步 SOP：①拆爆款标题卖点 ②找核心属性 ③替换修饰 ④重组为新标题 → **多测几条**
📅 漏斗池
日常运营
每天 3+ 新品入库 + 9 时点上品日历（早 8/9:30/11:30/14/16/18/20/21/22）+ 1-3-7 天数据周期
**不做 1:1 完全搬运**！这是合规底线——你 6/9 决策："我们是选品平台，不是笔记生产平台"。工具只帮你**分析 + 测品**，不帮你**搬运爆款**。
5
🛡️ 数据安全 + 自动降级
——账号/IP/数据/降级 4 层级，全程保护不被封
**你不用管的技术细节**——工具自动跑：
🔐 账号层
Cookie 加密
你的账号信息加密存本地，不与他人混用
🌐 IP 层
频率自适应
操作速度 ≤ 真人节奏，避免被风控
📊 数据层
假数据过滤
刷量数据自动标红 + 数据源可回查
⚡ 降级层
手动备份
CDP 失败立刻降级为手动粘贴 + 工具跳转
你不会看到"账号被封"这种事——**降级是默认行为**，不是异常。
